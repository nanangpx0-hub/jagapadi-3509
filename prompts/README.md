# Prompt Templates JAGAPADI

Folder ini berisi prompt model-agnostic untuk AI apa pun. Pakai bersama file konteks ringkas di root repo:

- `AGENTS.md`
- `PROJECT_SUMMARY.md`
- `TECH_STACK.md`
- `CURRENT_TASK.md`
- `DATABASE_SCHEMA.md`
- `DATA_DICTIONARY.md`

Cara pakai:

1. Pilih template sesuai pekerjaan.
2. Isi bagian placeholder yang diberi tanda kurung siku.
3. Lampirkan file konteks yang relevan saja agar muat di model dengan context window terbatas.
4. Untuk pekerjaan kode, minta AI menyebut file yang disentuh dan cara validasinya.

Template tersedia:

- `code-review.md`
- `new-feature.md`
- `debug-error.md`
- `documentation.md`

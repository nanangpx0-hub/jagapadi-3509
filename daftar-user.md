## Otentikasi & Password

- Password disimpan dalam format **hash BCrypt** (cost: 12) di kolom `password` tabel `users`.
- Password tidak dapat dibaca/dilihat secara langsung.
- Proses login memverifikasi password dengan `password_verify()` (lihat `app/models/User.php:252-272`).
- Password default untuk user baru dapat diatur di panel admin atau melalui command-line PHP.

## Cara Menambah User Baru

### 1. Melalui Admin Panel

Navigasi ke halaman manajemen user → klik "Tambah User" → isi form.

### 2. Via Command Line (CLI)

```php
<?php
require 'config/database.php';
$db = Database::getInstance()->getConnection();

$stmt = $db->prepare("
    INSERT INTO users (username, password, email, nama_lengkap, role, aktif, created_at) 
    VALUES (?, ?, ?, ?, ?, ?, NOW())
");

$hashed = password_hash('Jagapadi1!', PASSWORD_BCRYPT, ['cost' => 12]);
$stmt->execute(['username_baru', $hashed, 'email@domain.com', 'Nama Lengkap', 'petugas', 1]);
```

Simpan script di file `.php` lalu jalankan dengan `php filename.php`.

## Troubleshooting

**Lupa password?**  
Hubungi administrator untuk reset password via admin panel atau command line.

**Login gagal?**  
- Pastikan username tepat (case-sensitive untuk email)
- Password `Jagapadi1!` untuk user non-admin
- Akun harus dalam status `aktif = 1`

**Ubah password setelah login:**  
Dashboard → Profile Settings → Change Password
